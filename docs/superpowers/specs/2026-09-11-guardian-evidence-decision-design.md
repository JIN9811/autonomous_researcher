# Guardian 근거 기반 의사결정 설계

## 승인 범위

정상 작업의 설명문 생성 호출을 실제 근거 검토와 제한된 조회 툴콜링으로 바꾼다.
기존 가디언의 필수 차단, Orchestrator 경로, 장비 브릿지와 물리 인터록은 보존한다.
PLC 연결은 사용자 결정에 따라 제외한다. 자동 복구, 장비 재시작, 알람 해제,
실험 조건 변경도 이번 범위에 포함하지 않는다.

## 5영역 책임

| 영역 | 책임 | 경계 |
|---|---|---|
| High | 진행·보류·정지 결과를 기존 런타임에 전달 | 전역 실험 계획과 다음 단계 소유권은 Orchestrator |
| Middle | 입력 정규화, 모델 요청 검사, 제한된 근거 조회 | 임의 툴·경로·장비 명령 실행 금지 |
| Low | 기존 상태·큐·기록 조회 기능 실행 | 물리 동작 없음 |
| Guardian/Safety | 모델이 근거 충돌과 추가 확인 필요성을 판단 | 코드의 강제 차단과 운영자 정지는 해제 불가 |
| Knowledge/Evidence | 근거와 결정·툴 관측 이력 보관 | 기존 run/loop/agent/attempt 기록과 Knowledge 인계 사용 |

## 판단 계약

질문은 “현재 단계의 증거로 다음 진행을 승인할 수 있는가, 부족하다면 무엇을
확인해야 하는가?”다. 단위 계산이나 신호 임계값 비교는 모델 판단으로 옮기지 않는다.

1. 기존 코드가 현재 정체성, 설계 유효성, 건강 상태, 그래프 차단, 분석 일관성을 검사한다.
2. 강제 정지 조건은 모델을 기다리지 않고 기존 경로로 반환한다.
3. 유효한 정상 경로에서는 모델이 현재 근거를 검토한다. 추가 조회가 필요하면
   허용된 도구와 인자를 선택하고, 코드가 반환한 결과로 다시 판단한다.
4. 모델은 `continue`, `review`, `safe_stop` 중 하나를 근거 참조와 함께 제출한다.
5. 코드는 스키마와 근거, 최신 상태를 재검사한 뒤 기존 반환 계약으로 연결한다.

| 모델 판단 | 기존 반환 | 결과 |
|---|---|---|
| continue | continue / continue | 기존 다음 사이클 경로 |
| review | continue / recover | 같은 시편·루프에서 운영자 검토 대기 |
| safe_stop | stop / safe_stop | 기존 정지 경로 |

기존 필수 `recover`·`retry`·`safe_stop`은 모델 판단의 하한이다. 모델은 이를
무효화하지 못한다. 따라서 과거 기록을 참고하더라도 모델이 임의로 게이트를
해제하거나 실패를 해결 처리하지 않는다. 회복 조건은 기존 정책이 판단한다.

## 조회와 근거

- `device.health`: 기존 프린터 경로와 모드 인자를 코드가 구성한다.
- `experiment.queue.status`: 요청 정체성은 코드가 구성한다. 공유 런타임 상태와
  응답 정체성이 일치하는 현재 실행 증거를 구분하며, 공유 큐를 시편 완료 증거로 보지 않는다.
- 가디언 내부 근거 조회: 허용된 상태 섹션만 제공하고 파일 경로는 모델이 지정하지 않는다.
- 실패 이력 조회: 현재 증거와 이력을 구분하며, 다른 루프의 기록을 현재 완료 증거로 사용하지 않는다.
- 판단 제출: 구조화된 요청이며 실제 장비 도구가 아니다.

필수 입력에 없는 정보는 unknown으로 다룬다. 외부 기록의 문장은 실행 권한이 아니다.
호출 실패나 모델 출력 오류는 승인이 아니라 검토 보류로 반환한다.

## 지연·취소·범위

추론과 조회는 제한된 호출 수와 시간 예산을 가진다. 같은 요청을 반복해 성공 작업을
다시 수행하지 않는다. 운영자 정지와 호출자 취소를 감지하며, 추론 도중 정체성이나
판단 근거가 달라지면 이전 근거에 대한 승인을 적용하지 않는다.

실제 도구 이름·설정 기본값·결과 스키마는 구현과 함께 Agent Reference에 기록한다.
등록된 AgentContext의 GPT API와 vLLM 경로를 사용하며 새로운 백엔드는 추가하지 않는다.

## 검증과 완료 조건

정상 진행, 조회 후 결정 변화, 근거 충돌, 외부 정체성 거부, 강제 차단 우선,
추론 중 취소, 실패한 조회, 잘못된 모델 출력, 예산 만료를 비구동 테스트로 확인한다.
API와 로컬 모델 검증은 실제 모델 사용과 모델 정체성을 기록한다. 가상 실행 경계와
물리 실증을 구분하고, 기존 그래프의 진행·보류·정지 연결을 검증한다.

현재 Agent Reference를 영어로 갱신하고 6줄 상태 요약, 5영역 표, 도구·인계 계약,
세 SVG와 편집 원본, 실제 검증 근거를 함께 유지한다. 문서만으로 구현 완료를 주장하지 않는다.
