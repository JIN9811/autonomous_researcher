## BO checkpoint used in both guides

After Analysis and Knowledge hand valid evidence to BO, open `/bo` or select
the BO Agent in Live GUI. Confirm the objective identity/equation first, then
inspect the posterior mean, 95% confidence interval, measured observations,
next point, and acquisition panel. The default parameter slice and the
candidate-index audit must report the same completed BO step. Completion adds
PNG, SVG, and CSV files to the run's BO artifacts; those files document the
projection but do not authorize Design or physical execution.
