# ATR Live GUI + LangGraph Package

This package contains Codex-ready implementation instructions and UI/UX/backend/graph specs for the ATR Runtime IDE.

## Files
- ATR_Live_GUI_and_LangGraph_Codex_Instructions.txt: main Codex prompt/instructions.
- docs/UI_SPEC.md: visual layout and component spec.
- docs/UX_SPEC.md: interaction and runtime behavior spec.
- docs/BACKEND_API_SPEC.md: backend API and event types.
- docs/GRAPH_INTEGRATION_SPEC.md: LangGraph config/compiler/runtime integration.
- schemas/*.json: initial JSON schemas.
- frontend/design_tokens.css: CSS tokens and effects.
- frontend/component_map.json: suggested frontend component map.
- backend/runtime_event_types.py: Python event type reference.
- assets/reference/*.png: reference images.
- assets/icons/*.svg: placeholder production-ready SVG icons.

## Intended Use
Give this entire ZIP package to Codex together with the existing project repository. Tell Codex to implement incrementally while preserving existing working backend behavior.
