# Evolution Lab UI Spec

Use the existing futuristic ATR UI language.

Panels:
1. Target selector
2. Source trace selector
3. Evolution pipeline diagram
4. Candidate leaderboard
5. Variant diff viewer
6. Gate result checklist
7. Version lineage
8. Activation controls

Effects:
- Active evolution step: cyan/violet glow pulse
- Failed gate: red border + warning icon
- Gate passed: green check badge
- Unreviewed variant: amber unread badge
- Active candidate: luminous outline
- Rollback path: dashed orange line
