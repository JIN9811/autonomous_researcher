# Workspace icons

Seven shared navigation pictograms for the Main GUI and workspace references.
Generated with `gpt-image-2.5-sunburst` through the Image API using the bundled
image-generation CLI. The navy/cyan palette follows the AX4LAB document theme.

The exact per-icon prompts and generation settings are recorded in
[workspace-icons.jsonl](../../../docs/assets/presentation/workspace-icons.jsonl).
These icons identify workspaces; they do not represent device availability,
experimental evidence, or safety approval.

The Main GUI uses one compact icon/name/Workspace cell per destination. Each
opens a separate window; operational status and detailed controls remain in
the destination workspace.

All seven destinations share the AX4LAB logo entrance: white transitions to
pale sky blue, with the workspace name in navy underneath. The 1.7-second
presentation does not await device readiness; Escape, reduced-motion settings,
and the shared startup fallback remain supported. Navigation pictograms are
used on the Main GUI and in documentation, not on the entrance cover.
